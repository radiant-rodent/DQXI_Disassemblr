## Open problems

1. **`maybe_` vs `g_` prefix conflict.** The task says to prefix names below 0.50 with `maybe_`,
   and gives `maybe_g_<section>_<hex>` as the honest fallback, but
   `tools/typedb/apply.py:check_identifier(name, prefix="g_")` rejects any name that does not start
   with `g_`. I used `maybe_g_...` (the majority spelling in finished batches, 105 entries) for the
   two low-confidence names. The merge step must either accept/normalise `maybe_g_*` or G_002's
   `g_maybe_*` alternative; otherwise those two entries will be dropped with an error.
2. `0x007A2CFC` is write-only in this image (one statement, one function). Its gameplay meaning
   (skip? camera toggle? debug latch?) cannot be proven statically.
3. `0x007C8608`'s class is identified structurally (parent/factory/predicate, vtable
   `0x00762FEC`, list-panel `InitPanes`) but the class has no entry in `structs.json`, so the name
   `listPanelClassRecord` is a role description, not a recovered class name.
4. No emulator/hardware run; nothing here is runtime-verified.
