### 1. `0x007AEA72` -> `g_hidDisableSelectRemap` (`u8`, confidence 0.85, `.data`, initial value 0x00)
- **Role**: Configuration flag controlling hardware SELECT button behavior.
- **Decompilation Analysis**:
  - Located at byte address `0x007AEA72` in `.data` (initial value 0).
  - Read via literal pool entry `0x0011276C` by `Hid_ReadPadState` (`0x00112640`).
  - Read via dedicated getter function `0x001125AC` (literal `0x001125B8`) by `Input_ReadPadState` (`0x0010C2D4`).
  - When `*0x007AEA72 == 0` (the default initial state), both pad read routines invoke `0x0011AAF0` (via wrappers `0x001148E4` and `0x0011AAE0`).
  - `0x0011AAF0` inspects the active pad state bitmasks (held buttons at offset +0, newly triggered at +4, and released at +8) and automatically mirrors/remaps SELECT (`KEY_SELECT`, bit `0x04`) into START (`KEY_START`, bit `0x08`), clearing the raw SELECT bit and unifying simultaneous presses.
  - When `*0x007AEA72 != 0`, `0x0011AAF0` is bypassed, allowing SELECT to be processed as an independent button without START remapping.

### 2. `0x007AF0DC` -> `g_camSleepCameraState` (`u8[8]`, confidence 0.85, `.data`, initial value `0xFFFF0000`)
- **Role**: 8-byte CTR-SDK camera sleep state record and control flags.
- **Decompilation & Service Analysis**:
  - Located at `0x007AF0DC` in `.data` (8-byte block initialized to `0xFFFF0000`, followed by zero word at `0x007AF0E0`).
  - Referenced by literal `0x00114790` in `0x00114728` (called prior to applet suspend/sleep in `0x0010D504` and before the `nn::err` fatal error applet in `0x0051C2A0`) and literal `0x0011A808` in `0x0011A7D0` (resume/wake path).
  - Both functions inspect byte +1 (`0x007AF0DD`): when non-zero, they interact with the `cam:u` camera service via session handle `0x007B0054`.
  - `0x00114728` queries camera status via commands `0x003B0000` (`cam:DriverFinalize`) and `0x003C0000` (`cam:GetSleepCamera`), ORs the status bytes, and writes the resulting camera mask into byte +0 (`0x007AF0DC`). It queries command `0x00130040`, checking against error literal `0xC9405001` (3DS Result Code: Level 25 Status, Module 20 CAM, Description 1); if matched, it calls command `0x003D0040` (`cam:SetSleepCamera(0)`).
  - `0x0011A7D0` restores the saved camera state from byte +0 (`0x007AF0DC`) via `cam:SetSleepCamera(state)`.
  - Previously miscategorized under `HID` / `SVC` due to address proximity to HID routines in `.text`.
