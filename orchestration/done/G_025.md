### 1. Button Mapping Tables
- **`0x007354FC`** -> **`g_hidPadButtonMasks`** (`u32[24]`, confidence 0.90, `.rodata`)
  - Array of 24 32-bit hardware button masks for standard 3DS buttons (indices 0..15: D-Pad Left/Right/Down/Up, C-Stick Left/Right/Down/Up, Start, Select, A, B, X, Y, L, R) and Circle Pad Pro / New 3DS extended buttons (indices 16..23: ZL, ZR, Circle Pad Left/Right/Down/Up).
  - Iterated by `Input_UpdatePadState` (0x00108A00) via literal `0x00108BF8` in a loop over 16 (standard 3DS) or 24 (New 3DS / CPP active) entries to translate raw 3DS HID bitmasks into engine button flags.
- **`0x007AEB04`** -> **`g_buttonMappingTable`** (`u32[19]`, confidence 0.90, `.data`)
  - 19-entry mapping table of 32-bit masks indexed by `Input_UpdateButtonMasks` (0x00108878) via literal `0x001089F8`.
  - Translates input snapshot states into engine button bits 0..18; slots 4..7 are zeroed out because directional bits 4..7 are computed dynamically from analog stick threshold floats (`0xBEE66666`).

### 2. Static Call-Once Guards (`__cxa_guard`)
- **`0x007AE728`** -> **`g_padDeviceInitGuard`** (`u32`, confidence 0.90, `.data`, initial value 0)
  - One-time static initialization guard (`__cxa_guard`) in `.data` checked and acquired via `0x0010009C` by `Input_Initialize` (0x00105044) via literal `0x0010519C` before constructing the global pad device object at `0x007E3058` via `0x001072C0`.
- **`0x007AE72C`** -> **`g_buttonSnapshotInitGuard`** (`u32`, confidence 0.90, `.data`, initial value 0)
  - One-time static initialization guard (`__cxa_guard`) in `.data` checked and acquired via `0x0010009C` by `Input_Initialize` (0x00105044) via literal `0x00105190` before constructing the global button/touch snapshot record at `0x007E3040` via `0x001072B0`.

### 3. Input State Objects and Raw Sample Buffers
- **`0x007E3040`** -> **`g_globalTouchState`** (`u8[24]`, confidence 0.85, `.bss`)
  - 24-byte (`0x18`) touch panel and button snapshot record spanning `0x007E3040` to `0x007E3058`.
  - Constructed in `Input_Initialize` under guard `0x007AE72C` with vtable `0x001072B8` and flags at +0xA and +0xB; passed to `Input_UpdateButtonMasks` and `Input_ReadTouchState` to track raw touch samples and previous edges.
- **`0x007E3058`** -> **`g_globalPadSnapshot`** (`u8[160]`, confidence 0.85, `.bss`)
  - 160-byte (`0xA0`) circle pad and analog stick snapshot object in `.bss`.
  - Constructed in `Input_Initialize` under guard `0x007AE728` with vtable `0x0078110C`; contains two stick sub-objects at +0x8 and +0x2C, previous button state at +0x54, raw pad buffer at +0x58, and init flag at +0x98.
  - Passed as pad snapshot parameter (`snap`) to `Input_UpdatePadState` (0x00108A00) and sampled by `Input_ReadPadState` (0x0010C2D4).
- **`0x007F25CC`** -> **`g_rawTouchSampleBuffer`** (`u8[12]`, confidence 0.85, `.bss`)
  - 12-byte raw touch panel hardware sample buffer in `.bss`.
  - Passed to service query `0x001148F0` via literal `0x0010C2D0` in `Input_ReadTouchState` (0x0010C1C8); receives 3 halfwords at +0x0/+0x2/+0x4 (touch x/y/status) and 4 signed bytes at +0x6/+0x7/+0x8/+0x9 (delta x/y/pressure) which are scaled by `0x00114798`.
