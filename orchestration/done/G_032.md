## Subsystem Context: MoLive
MoLive is the media streaming and decoding pipeline (providing video streaming and audio stream playback). It operates via a `MoLiveReader` (`0x14D0` bytes) created by `MoLive_Decoder_Create` (`0x006B9694`). The decoder interacts with memory via allocator callbacks at `0x007AE5D4`, reads packets through a source adapter at reader offset `+0x14C0`, and dynamically allocates per-stream filter and decoder nodes (types 1, 2, 3, 4) into an AVL / Red-Black tree stream map.
