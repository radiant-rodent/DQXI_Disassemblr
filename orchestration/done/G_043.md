# G_043 — Script globals (300) — DONE

## What was done

Resumed batch G_043 (subsystem: Script, 300 globals: 26 in `.rodata` from `0x00726F66` to `0x00797274`, and 274 in `.data` from `0x007AEAC0` to `0x007C1594`). No partial output file existed, so all 300 globals were analyzed, named, typed, and verified from scratch.

Every global's address and literal-pool references were checked against the retail ARM image (`original/exefs/code.decompressed.bin`), the disassembly files (`asm/rodata/`, `asm/data/`, `asm/text/`), and Ghidra decompilation in `decomp/`.

### Categories and Findings

In reality, these literal slots contain inline ASCII keyword strings `"for\0"` (`0x00726F66`) and `"try\0"` (`0x00797274`), which coincidentally decode as little-endian words falling within the `.rodata` address range. They are honestly named `maybe_g_rodata_00726f66` and `maybe_g_rodata_00797274` with full evidence documenting their origin.
