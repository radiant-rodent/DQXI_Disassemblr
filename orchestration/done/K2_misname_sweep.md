## 1. Summary of Work Done

First-pass function names assigned during early decompiler passes frequently suffered from **cascade misnomers**: an incorrectly named callee led every upstream caller to inherit an erroneous subsystem prefix (e.g. dozens of combat damage calculators named `Text_CalcRow*`, party tactics AI routines named `Ui_TextLayout_*`, and dialogue argument setters named `Actor2D_DebugPrint*`).

To systematically discover and repair these misname families across the entire 18,787-entry-point binary:
1. Developed `tools/research/misname_sweep.py`, an automated analysis tool implementing 12 ground-truth `FactRule`s based on verified invariants in `orchestration/naming/FACTS.md` (e.g. `Item_LookupRecord`, party member struct layout, battle message queue spawner, message format argument slots, battle RNG `0x001CA474`, CTR SDK fatal error applet).
2. The tool scanned all 18,787 entry points in `build/code.bin` across both ARM and Thumb instructions and literal pools, identifying 199 candidate functions whose current subsystem names contradicted ground-truth callees.
3. Inspected each candidate in disassembly and decompiled C, partitioning them into 10 cohesive misname families (156 true misnames) and identifying 43 false positives (legitimate cross-subsystem callers).
4. Authored `orchestration/naming/refine/out/R_S02.json` containing 156 corrected function proposals complete with verified C signatures, detailed summaries, confidence ratings, and assembly evidence.
5. Appended new ground-truth facts to `orchestration/naming/FACTS.md`.
6. Verified with `python tools/merge_names.py --check` (0 bad entries, 0 unknown addresses), merged with `python tools/merge_names.py`, rebuilt with `python tools/build.py` (bit-match PASS, 0 differences), verified with `python tools/verify_project.py` (OVERALL PASS), and passed all 384 test cases in `python tests/run_all.py`.
