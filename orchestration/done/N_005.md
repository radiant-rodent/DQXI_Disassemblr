## Method

1. **Index.** Built a one-off index over all 18,367 readable C files
   (`decomp/readable/functions` + `decomp/readable/recovered`): address → filename, address →
   callees, and the inverted caller map. Every batch entry had a readable C file, so no fallback
   to `decomp/ghidra/` was needed.
2. **Name map.** Merged `symbols.json`, `symbols_recovered.json`,
   `decomp/native_names.json` and **all** existing `orchestration/naming/out/*.json`
   (N_001–N_004), so the batch reuses the established vocabulary (`Mem_AllocAligned`,
   `Gfx_CreateMeshObjectByParams`, `Gfx_AddFColAnimator`, `Ui_ListWindow_SetRowsPerPage`,
   `Battle_ActionAnimWindow_Init`, `maybe_Ui_ScreenController_InitChildren`, …).
3. **Strings and vtables.** All literals resolved against
   `original/exefs/code.decompressed.bin` (file offset = address − `0x100000`); vtable pointers
   are `.text` literal-pool words, so each candidate slot function could be placed in its class
   table (`refs to 0x…` → rodata address → base = ref − slot). Example: `0x003F0C38` is slot
   `+0x34` of class base `0x0076B934`, whose `+0x50` slot is `0x003F0B84`.
4. **Bottom-up helpers** identified once and then cited in evidence:
   | helper | role |
   |---|---|
   | `0x001A6520` (`drN`) | shared UI base-window initialiser (sets up cursor panes) |
   | `0x003E00CC` / `0x003E043C` / `0x003DFF34` | bind pane / show-hide pane / enable pane |
   | `0x001A6230`, `0x001A6680`, `0x001A6768` | child-layout animation start / finish |
   | `0x005F541C`, `0x005F2B54` | UI/effect sub-object base initialisers |
   | `0x001235A4` + `0x006F41A4` | intrusive-list link / commit |
   | `0x00336054`, `0x002E5934`, `0x002E59B8`, `0x002E5C60`, `0x002E5D0C`, `0x002E5E18` | sprite-actor child creation variants |
   | `0x0028E754`, `0x0028E940` | mesh creation + fCol colour animator |
   | `0x002A8BA4` | battle action-anim element registration (slot, element) |
   | `0x00299B94`, `0x0062202C` | per-row data sub-object, pager binding |
   | `0x00672E44`, `0x00673BC8` | sin/cos pair used by the arc keyframe builder |
