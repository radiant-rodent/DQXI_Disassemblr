## Method

1. Name map (556 project names + 11,314 sibling names) from `symbols.json`,
   `symbols_recovered.json`, `decomp/native_names.json` and all 82 existing `out/N_*.json`
   (`N_014.json` is invalid UTF-8; skipped for the collision scan).
2. Caller index over all 18,367 readable C files (`decomp/readable/{functions,recovered}`), after
   stripping the generated header comment (otherwise every function "calls" itself).
3. Per-function digest (signature, size, annotated callers/callees, globals, string literals, full
   body) â€” all 150 bodies (378,393 chars) were read.
4. **Ground truth for helpers Ghidra never split**: the callees of this batch are mostly interior
   addresses with no entry in `functions_merged.jsonl` (e.g. `0x00100050`, `0x00116AE0`,
   `0x0011CB38`, `0x005F5818`, `0x0063DCA4`). These were disassembled directly out of
   `asm/text/text_*.s`, which settled the three most load-bearing facts in the lane:
   * `0x00100050` = *construct-array* â€” `for (i = 0; i < count; i++) { ctor(dst); dst += stride; }`.
     This is why ~40 functions here are constructors with `construct-array(dst, g_ctor, size, n)` at
     the end.
   * `0x00116AE0` = `memset(p, 0, n)`; `0x00116C10` / `0x00116A14` = word/byte `memcpy`.
   * `0x00100B74` = `std_U16StrLen` (counts UTF-16 words to the NUL) â€” Ghidra marks it
     "does not return", which had made two "recovered" bodies look like aborts.
   * `0x0011CFAC` = unsigned integer division (used as `align_up(v,a) = div(v+a-1,a)*a`), and
     `0x0011FE8C` = popcount.
5. String resolution: dumped printable runs from `original/exefs/code.decompressed.bin` (base
   `0x00100000`) and followed each `g_XXXXXXXX` through one u32 load. This produced the only two
   real string anchors in the batch: `'base'` at `0x001B86DC` (â†’ `maybe_Ui_Node_FindBaseChild`) and
   `"OnInnMapJumpEvent"` at `0x0024CAFC` / `"ATrgMapJumpEvent"` at `0x00251593` /
   `"xp::CutsceneID"` + `"wrong number of parameters"` at `0x002515A8..0x2515B0`
   (â†’ `Event_RequestInnMapJump`, `Script_Native_ATrgMapJumpEvent`).
6. Bottom-up: leaf accessors and constructors first, then their callers (e.g. the
   `Ui_OverlaySlotCtor_*` trio was only separable once `Ui_Overlay_CreateSlotWidget` was named by
   N_045/N_077).
