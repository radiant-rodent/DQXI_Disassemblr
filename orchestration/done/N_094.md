## Architectural Findings & Subsystem Breakdown
The batch header label `"Save_and_Persistence"` was an artefact of early automated batch grouping (only ~5 functions in this range touch save/senreki flags). Through cross-referencing callers, callees, vtables in `.rodata`, and literal pools in `original/exefs/code.decompressed.bin`, the range was determined to comprise three primary engine layers:

1. **Animation, Model & UI Vector Helpers (`0x005A7194` - `0x005B1C70`, 18 functions)**
   - `0x005A7194`: `Ui_SortedByteList_EraseValueAndSort` (`std::vector<u8>` value removal via `std::memmove` at `0x00111378` and introsort via `0x0071FBA8`).
   - `0x005A73E4`: `Gfx_KeyframeTrack_DispatchHandler` (dispatches to handler table `0x7A2DE8` indexed by `*(u16*)(trackData + 2)`).
   - `0x005A8000`: `Model_Instance_DispatchCallback` (flushes drawing context via `0x0055AAAC` and invokes `model->f_a4`).
   - `0x005A8378` / `0x005A8F50` / `0x005A9C0C`: 3D model render object construction and material binding installing vtables `0x78348C`, `0x7834A0`, and `0x7834B4`.
   - `0x005ABEB4` / `0x005ACB04`: `Anim_KeyframeTrack_EvaluateAll` and `Anim_KeyframeTrack_ResetState` (animation track evaluation for cutscene and battle objects).
   - `0x005AFF48`: `Math_Vec3_LookAtRotationMatrix` (orientation matrix math from direction and up vectors, called by camera and actor orientation updates).
   - `0x005B0138` / `0x005B01AC`: `Work_ItemEntry_CompareByPriority` and `Work_ItemEntry_CompareByName` (`std::sort` comparator callbacks querying item records from data manager `0x0011CB38` / `0x0063E4C4`).
   - `0x005B1888` - `0x005B1C70`: `Save_Senreki_CountCompletedFlagsA` through `E` (5 functions referenced in table `0x00645368` tested by `0x00644CA8`, testing save data flag bitfield at `saveData + 0x4B30` against 10, 14, 9, 14, and 12 groups of 4 flags in tables `0x005B190C`..`0x005B1CF4`).

2. **Squirrel 2.2.5 VM Execution Core (`0x005B43F4` - `0x005BAAD4`, 6 functions)**
   - `0x005B43F4`: `Sq_VmRaiseIdxError` (`SQVM::Raise_IdxError` with string `"the index '%.50s' does not exist"` at `0x005B4458`).
   - `0x005B4C34`: `Sq_VmPop` (`SQVM::Pop`, popping and nulling `_stack` slots).
   - `0x005B516C`: `Sq_VmCall` (`SQVM::Call`, call frame setup and closure execution).
   - `0x005B5660`: `Sq_VmPushNull` (`sq_pushnull`, pushing null onto stack top).
   - `0x005B57E4`: `Sq_VmCreateInstance` (`SQVM::CreateInstance`, allocating 0x24-byte `SQInstance` and initializing default values from class `OT_CLASS`).
   - `0x005BAAD4`: `Sq_VmToString` (`SQVM::ToString`, formatting primitives with `"%g"` / `"%d"` or invoking `_tostring` metamethod).

3. **Field2D Engine: 2D-Mode Map Chips, Sprites, and Scene Rendering (`0x005BB8DC` - `0x005D07B8`, 125 functions)**
   - `0x005C1D64`: `Field2D_Scene_BuildFromMapData` (the central 0x1238-byte scene construction routine, allocating 0xE0-byte actor elements and 0x20-byte layer structures via `std_ConstructArray` at `0x00100050` with constructors `0x0070DA50` and `0x005C2194`).
   - `Field2D_MapChip_*`: Grid terrain analysis, column rendering, tile passability checks, collision step queries (`0x005C0610`), stair/slope edge transitions, ray tracing (`0x005BE14C`), and pathfinding (`0x005C4720`).
   - `Field2D_Sprite_*`: Actor movement tweens (`0x005BBEBC`, `0x005C8A08`), floating/bobbing oscillation (`0x005BBC60`, `0x005C96B8`), ground shadow projection (`0x005CC2E4`), direction animation (`0x005C1994`), and overhead dialogue/status glyph quad attachment (`0x005CD634`, `0x005CD7F8`, `0x005CE868`).
   - `Field2D_Scene_*`: Layer management (`0x005C2F9C`), AABB actor collision boxes (`0x005BDA18`), Z-order sorting (`0x005CC590`), and PICA200 textured quad vertex emission (`0x005CF034`, `0x005D00C0`).

4. **Field Gimmick Configuration (`0x005D14A0`, 1 function)**
   - `0x005D14A0`: `Field_Gimmick_BuildRowListFromConfig` (called by `Field_Gimmick_RebuildRows` and `Field_Gimmick_SetupListFromConfig` to parse 28-byte gimmick interaction descriptors).
