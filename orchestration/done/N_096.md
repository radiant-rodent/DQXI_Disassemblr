## 4. Key Discoveries

1. **`0x0060C530` / `0x0060C5F8` Ghidra Split:**  
   Ghidra truncated `0x0060C530` at `blx #0x100050` because `std_ConstructArray` was flagged non-returning. The subsequent instructions starting at `0x0060C5F8` represent the second half of the loop (walking party units at `Game_GetWork()+0x4260/+0x4264`, checking unit IDs with `0x00639B74`, and computing unit 3D positioning).
2. **Field Actor Scale and Bounding Box Virtual Table Slots:**  
   `0x00628B2C` and `0x00628CE0` appear as consecutive slots across 6 distinct `Field_Actor` / `Field_SceneObject` vtables. `0x00628B2C` calculates the 3D model scale Vec3 using scale factors from `0x006289CC`, while `0x00628CE0` retrieves the axis-aligned bounding box.
3. **PICA200 GPU Command Layer:**  
   The cluster at `0x006555E0`–`0x00657E68` is a low-level graphics driver layer directly writing 32-bit PICA GPU command packets and register headers (`0x00657e00`, `0x00658008`), including texture sampler wrap modes, mipmap clamps, and combiner states.

   `0x0011CB38` returns the master `DataManager` singleton. Functions in this batch query specific data tables through standard accessors:
