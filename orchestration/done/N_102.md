## Key Discoveries & Technical Details

1. **Standard CRT & Wide String Primitives (`0x001000FC` - `0x00100F06`)**:
   - `0x001000FC`: `std_Abort` is the thumb thunk jumping directly to runtime terminate handler `0x0011C810`.
   - `0x001009E0`: `std_MemCmp` is an optimized memory comparison comparing 32-bit words when aligned and falling back to byte comparisons upon mismatch.
   - `0x00100AFE` & `0x00100B32`: textbook `wcspbrk` and `wcsstr` implementations operating on 16-bit wide character null-terminated strings.
   - `0x00100C0C`: `std_GetErrno` queries `__aeabi_errno_addr` (`0x002FF9C4`) and returns `*errno`.

2. **Squirrel Scripting Engine Bindings (`0x0014872C` - `0x00159048`)**:
   - `0x0014872C`, `0x00148764`, `0x001488C2`, `0x00148AB0` form a native string tokenization routine that queries VM stack arguments via `func_005B5C6C`, builds a Squirrel array via `Sq_Array_Create` (`0x005F9D8C`), and assigns string objects with `Script_ObjectPtr_Assign` (`0x001BF7D8`).
   - `0x0014AB90` is `Script_ArrayAppend` (`Array.append` / `Array.extend`), retrieving array and argument from the Squirrel VM stack and delegating to `0x005F9EF4`.
   - `0x001532BC` is the comparator closure invocation inside Squirrel `array.sort`, directly surrounded by error string literals `compare func failed` and `numeric value expected as return` at `0x0014CD12`/`0x0014CD1C`.
   - `0x00159048` is `Script_PushCurrentScene`, retrieving active scene via `0x00245D5C`, pushing to the VM stack with `0x006BC6C8`, and returning 1.

3. **3DS HID Controller Pad Decoder (`0x00152ECA`)**:
   - `Input_ProcessKeyCallbacks`: decodes 3DS HID button bitmasks (0x100: R, 0x200: L, 0x400: X, 0x8000: Touch) and invokes registered callback handlers.

4. **FieldActor Virtual Methods at `0x00729010` (`0x001664AC` - `0x00167580`)**:
   - `0x001664AC`: `Field_Actor_InitProperties` is the second half of `FieldActor` constructor `0x00166308` (which Ghidra truncated due to assuming `std_ConstructArray` was non-returning).
   - Functions 16 to 32 (`0x00166B7C` - `0x00167580`) all belong to the virtual table at `0x00729010` in `rodata_00725000.s`:
     - Render visibility setters delegating to `Gfx_Node_SetVisible` (`0x0029126C`) on sub-object `self + 0x32C` (`Actor_Node_ShowVariantA..I`).
     - Motion frame updates evaluating state byte `0x48C` (states 2..5), updating `&self->f_488` via `func_0062B24C`, and notifying listener `+0x11C`.

5. **Field Gimmick Event Controllers (`0x00168A58` - `0x00175034`)**:
   - Gimmick state machines interacting through controller `self->f_e4`: `Field_Gimmick_TriggerEvent3/15/14/16/4`, `Field_Gimmick_OnZoneChange`, `Field_Gimmick_CheckAllReady`.

6. **UI Widgets, Sliders & Senreki Menu (`0x00177080` - `0x001C4D58`)**:
   - Camp menu slider/bar widgets (`Ui_Bar_StartFadeIn`, `Ui_Bar_GetClampedValue`, `Ui_Bar_StartFadeOut`, `Ui_Bar_UpdateVisibility`) called by `maybe_Menu_Camp_SetSlotParam` (`0x00215DEC`) and `maybe_Menu_Camp_GetMaxSlotState` (`0x00215EAC`).
   - `0x001BB0A0`: `Menu_Senreki_QuestList_Init` loads layout definition `menu_senreki_quest` (`0x001BB108`) and binds layer `questlist` (`0x001BB11C`).
   - `0x001C3ED8` and `0x001C4D58`: `Ui_Layout_GetButtonState` / `Ui_Layout_GetButtonStateAlt` compute interactive button state codes (0: disabled, 1: normal, 2: focused, 3: pressed).

7. **Scene Graph Node Lifecycle (`0x0018BBE0` - `0x001BF798`)**:
   - Full reference-counting implementation: `Gfx_Node_Attach`, `Gfx_Node_Release`, `Gfx_Node_DetachChild`, `Gfx_Node_DtorBase`, `Gfx_Node_RefPtr_Release`.

8. **Party Member Slot Management (`0x0018D504` - `0x0018D5D8`)**:
   - `0x0018D504`: `Party_InitMemberSlots` initializes 20 slots (`0x14` iterations, stride `0x98`).
   - `0x0018D578`: `Party_ClearMemberSlot` zeroes 0x84 bytes and resets status fields `f_88, f_8c, f_90, f_91`.
   - `0x0018D5D8`: `Party_ResetSlotState` clears fields `0x38..0x74` and delegates to `Party_ClearMemberSlot`.
