## Method

1. **Global Name Map & Collision Avoidance:**
   Loaded `symbols.json`, `symbols_recovered.json`, `decomp/native_names.json`, and all 94 sibling batch files
   in `orchestration/naming/out/*.json` (14,532 total symbols). Every candidate name was validated against this database
   to ensure zero collisions across the entire decompilation project.
2. **Call Graph & Cross-References:**
   Built a cross-reference index across all 18,748 readable C files (`decomp/readable/{functions,recovered}`)
   and direct binary references (`bl`, `blx`, and literal pointer xrefs) against `original/exefs/code.decompressed.bin`
   (base `0x00100000`).
3. **Disassembly & Ghidra Mode Recovery:**
   Investigated all truncated bodies and `halt_baddata` artifacts by disassembling the exact ARM/Thumb bytes from
   `code.decompressed.bin` and matching them with `asm/text/*.s`. Several functions that Ghidra misclassified as Thumb
   were actually ARM code where `bl` instructions had been mis-decoded as Thumb `push` instructions.
4. **Vtable Dereferencing & RTTI Traversal:**
   Resolved virtual function tables in `.rodata` (`0x00725000`–`0x0079AA18`) containing target function pointers.
   Dereferencing adjacent virtual slots and class RTTI descriptors turned anonymous UI and Gfx pointers into
   identified class members.
5. **Incremental Progress Persistence:**
   Maintained output in `orchestration/naming/out/N_104.json` updated every 25 functions across 6 chunks.

## Load-Bearing Findings

* **Global Entity/Actor Handle Table `0x007B80C0` (`0x0022F5A0`, `0x0028E4AC`, `0x0028E500`, `0x0028E878`):**
  The central handle lookup mechanism across DQXI is resolved: `index = handle & 0x7FF`, with table base at `0x007B80C0`
  (stride 8 bytes: `{void* objectPtr, u32 generation}`). Validates `generation == (handle >> 11)`. `0x0022F5A0`
  (`Actor_ResolveHandleByRtti`) retrieves virtual method 0 (GetRtti) and walks the base class descriptor chain at `+0x0C`.
  `0x0028E4AC` (`Actor_ResolveHandleFast`) performs the fast non-RTTI check.
* **Squirrel Script Native Registration Tables & Binders (`0x0024D88C`–`0x0024F0E8`):**
  - `0x0024D88C` (`Script_NativeTable_ActorAim`), `0x0024DD34` (`Script_NativeTable_ActorActionSeq`), and `0x0024E4D4`
    (`Script_NativeTable_Actor2DMove`) are **static registration descriptor tables in `.text`**, pairing method names
    (e.g. `"ActorAimLocatorDirect"`, `"ActorAdvanceActionSeq"`, `"Actor2DMoveEx"`) with function pointers.
  - `0x0024EFBC` (`Script_BindDebugMenuNatives`) is a complete function registering the 8 debug menu natives into
    the Squirrel VM via `0x006BC528` (`Sq_BindNativeMethod`):
    `DebugCampLevelWorkEnable`, `DBOpenDialog`, `SetDebugMenuTitle`, `AddDebugMenuItem`, `IsDebugMenuSelect`,
    `GetDebugMenuSelectItem`, `StartDebugMenu`, and `EndDebugMenu`.
  - `0x0024ED44`..`0x0024EDFC` are sequential `Sq_BindNativeMethod` calls within `Script_BindActorNatives` (0x0024CBFC)
    binding `CanBootMiniGameGimmick`, `GetMiniGameCategoryFromGimmick`, `GetMiniGameIDFromGimmick`, `GetAltarGimmickID`,
    `ActorAttachGadget`, and `ActorRemoveGadget`.
* **Universal UI Window Close Delegate (`0x0028ED30`):**
  Function `0x0028ED30` (`Ui_Window_CloseAndHide`) is installed into **54 distinct UI window vtables** across the engine
  (`0x0075BD50`, `0x0075BF08`, `0x0075C004`, `0x0076A6F8`, `0x00770534`, etc.). It dispatches virtual methods `+0x40`
  and `+0x58` with state argument 4 (hide/close) and clears pending input at `self[0xAD] = 0`.
* **Weapon Ribbon Trail Mesh Engine (`0x0028C444`–`0x0028CD7C`):**
  A dedicated family implementing weapon sword trails (`Gfx_TrailMesh_*`, vtable `0x00727228`..`0x00727268`):
  `0x0028C444` (dynamic geometry update), `0x0028C7CC` (quad buffer reset), `0x0028C838` (fade alpha interpolation),
  `0x0028C8E0` (visibility check and draw dispatch), `0x0028CCE0` (clear emitter), and `0x0028CD7C` (is active query).
* **Casino Poker 5-Card Widget (`0x00294EA0`–`0x002952E8`):**
  Handled by table `0x0072A8F4`..`0x0072A92C`: `0x00294EA0` resets hold flags for 5 cards, `0x00294EF4` toggles card hold,
  `0x00295280` applies bet multiplier via `0x00636290`, and `0x002952E8` computes card ranks/suits and evaluates winning hand tier.
* **Map Viewport Quest Icon Engine (`0x00291818`–`0x00293A34`):**
  Handles quest marker screen projections: `0x00291818` (transforms 3D world coords to 2D screen map via saturating float
  converter `0x006731EC`), `0x002918FC` (evaluates actor heading angle via `0x00672E44`), `0x00291E08` (binds quest actor),
  and `0x00292430` (clamps off-screen icons to viewport boundary).
