## What was done

Batch `orchestration/naming/refine/batches/R2_004.txt` lists 90 low-confidence `maybe_`
functions (generated from the merged M1 state; batch files were not regenerated).

A previous worker had stopped after building a scratch analysis (`out/scratch/R2_004/`:
`batch_analysis.json` with callers/callees, and a draft generator). I reused its caller/callee
harvest but re-checked every verdict against the readable C, the now-named neighbours,
`symbols_recovered.json`, `scores.jsonl` neighbour lists, and — where relevant — the actual
bodies. Several claims in that draft could not be reproduced and were dropped (see below).

For each of the 90 functions I:

1. read the readable C header (previous name, confidence, proposal batch, evidence) and the body;
2. looked up real callers from a full index of `decomp/readable` (the batch's context score only
   counted callees for most of these), and checked the named callees' own headers;
3. cross-checked names against `symbols_recovered.json` and `scores.jsonl` (`neighbour_names`);
4. only then chose `confirmed` / `corrected` / `kept_maybe`.

## Deliberately rejected draft claims

The aborted draft contained several concrete-looking statements I could not verify and did not
carry over:

- “shared vtable method at slot +0x14 across 11 battle actor-action classes” for 0x004BC6D0 —
  the body is a state machine over `self[0x4A5]`; no such vtable registration is visible.
- “located in the Ui_SakusenWindow dispatch table at 0x0072A698” for 0x002A3A04 / 0x002A34D0 —
  the constants in the bodies are 0x0072A600 and 0x72A6C8 (a registration entry), and neither is
  a proven dispatch table. Both stay `maybe_`.
- “confirmed `Menu_TalkParty_ReleasePanels`” for 0x00216B5C — only one branch calls
  `Menu_TalkParty_ReleasePanel`; the rest is generic resource teardown, so the first-pass
  `maybe_Ui_ReleaseGfxResources` is kept.
- `Ui_BattleTargetMarker_CreateFromModelRecord`, `Ui_SpritePart_Update`,
  `Ui_Widget_SetValidHashId` were draft-confirmed; their owning classes are still inferred, so
  they stay below 0.5.
