## Decisions made without an orchestrator

- Batch order was kept for the JSON; decisions were always keyed by address so a resumed worker
  could merge partial chunks.
- Where a name was only "not contradicted" but the caller/callee evidence was still weak, I kept
  `maybe_` rather than inflating confidence (per the task note that a wrong confident name is worse).
- For the three `DebugLabel` siblings I corrected all three consistently even though only one has a
  named caller, because they share the same cluster and pane-image sequence; each is still `maybe_`
  at ≤ 0.40 because the exact field each one displays remains inferred.
