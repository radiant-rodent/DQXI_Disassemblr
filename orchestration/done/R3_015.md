   exists; it clears the five interaction flags (`+0x141..+0x145`, the same one-shot flag used by

   files get "no readable file found" and `decomp/xref.json` has no call edges for most of them
   (only 0x00387258 had a caller). I read the C files directly and used the sibling clusters, but
   their confidence is capped accordingly (0.45–0.50 only where the body is self-evident).

   `callees` entries are known to be mis-attributed where `functions.jsonl` boundaries are wrong
   (documented in the R3_007 entry). Verdicts that depended on callee names were cross-checked in
   the readable C where possible.
3. **Member-row block semantics** (`+0x16/+0x12`, record `+0xEE/+0x2EC`) are ambiguous; see above.
   A follow-up should read `0x00229C48`/`0x00229CC4` and `0x0018C184`/`0x0018C1B8` together with
   the `PartyMember` layout to decide whether `0x002CFB6C` is really a width fit or a cost preview.
4. **"Jockey panel" domain meaning unknown** (grid preview with per-cell scale thresholds and a
   10-second timeout). The family name is consistent across eight confident siblings, so I kept it.
