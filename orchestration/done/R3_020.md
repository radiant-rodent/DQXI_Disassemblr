merged names (named callers/callees, vtable siblings, `symbols.json`, `decomp/native_names.json`,

## Open problems / not verified

- **Sound channel block**: the halfword at `+0xBC` and the field at `+0x10` (default 2) have no
  proven meaning; whether the `+0x04/+0x08/+0x0C` floats are gains or playback rates is still open
  (the u16 at `+0x22` is already a rate, which favours gain, but that is an argument, not proof).
  Recovered layout is recorded in the AGENT_LOG entry so a later pass need not re-derive it.
- **0x0061D288**: the derived class (three extra handles at `+0x48/+0x54/+0x58`) is unnamed; the
  base is `Fs_Resource` (vtable 0x0077F6C4).
- **0x001EB180**: a named `Ui_ShopWindow_Dtor` already exists at 0x001C1B58, so which of the two
  shop classes this D1 body belongs to is unresolved.
- **0x0021FD38 / 0x00220338 / 0x0028A3FC**: layout owners still unknown (no constructor builds
  those exact arena counts).
- **0x00160D54**: the payload type of the 0x44-byte tagged record is unknown; the callee 0x006F0C10
  is still unnamed.
- **0x00163650**: readable body is damaged Thumb (`unaff_r4/r5/r6`, `in_CY`); kept at 0.30.
- No runtime/emulator check — this is a name-only change.
