# R3_029 — refine naming batch R3_029

**Status:** completed. 50/50 addresses decided, `python tools/check_refine.py R3_029` → `R3_029: OK`.

## What I did

Read the pre-baked dossier `orchestration/naming/refine/dossiers/R3_029.md` in five chunks
(10/10/10/10/10 functions), decided each function from its readable C plus named callers/callees,
vtable slots and (where the C was ambiguous) the disassembly, and appended the entries to
`orchestration/naming/refine/out/R3_029.json` after the first and second half.

Live `tools/fn.py` was used on ~20 addresses; `decomp/functions_index.json` (18,787 rows, the
authoritative name table) was used to resolve callee names that have no readable file. Six
single-address asm reads came from `asm/text/text_*.s` (no tree walk). No `asm/` or `decomp/` tree
walk was done, and the batch was not regenerated.

  all). I read the recovered files directly. Suggested fix: merge `readable/recovered` into
