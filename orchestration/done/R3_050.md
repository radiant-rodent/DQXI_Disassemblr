## Kept as `maybe_` (34) — and why

- **Six page input handlers** (0x0025B10C, 0x0025B838, 0x0025C1DC, 0x0025E380, 0x0025E4EC,
  0x0025B9A4): there is **no `bl` site for any of them anywhere in `asm/text`** — they are reached
  only through vtable slots, so the owning page class cannot be recovered from the call graph. The
  masks, animation ids and the row lookup (`Ui_RowData_AtIndex`) are verified; the class is not.
- **Nine lettered deleting destructors** (0x00299470, 0x003B498C, 0x003B567C, 0x002C0A24,
  0x002C0A60, 0x002C0E44, 0x002C0F54, 0x002C12A0, 0x002C1ACC): the *role* is certain, the *class*
  is not — `scores.jsonl` has no vtable row for any of them and none has a caller.
- **Damaged bodies**: 0x0029E4C6 (all `unaff_`), 0x0028ED6C (`unaff_r4..r6`, `in_lr`),
  0x0025B9A4 (`halt_baddata`), 0x002C3244 (truncated after the inline-storage guard),
  0x00280318 (comma expression + unrecovered jump table), 0x002A65E8 (mask read from `self`,
  widgets from `target` — Ghidra probably split one object into two parameters).
- **The two `0x003F31xx` twins** (0x003F3160, 0x003F3180): they share one body applied to the task
  object and to its 8-byte state sub-object, so at most one of the two names can be right.
- **The five `Ui_DateDisplay_EnterStateN`** (0x002C1EA8, 0x002C2020, 0x002C2048, 0x002C239C,
  0x002C25FC) plus 0x002C3148: the summaries were rewritten with the new facts (see below) but the
  class label is still only from the first pass.

## Facts worth carrying into `orchestration/naming/FACTS.md`

1. **0x00642710 is an 8-byte record accessor, not a timer start.** `ldr r0,[r0,#0x354]`; bounds
   check against `r0->f_60`; `return base + index*8`. The `Ui_DateDisplay_EnterStateN` literals
   (3/6/7/8/10) are **table indices**, not state numbers.
2. **0x0032BD58 is `func_0029126C(self + 0x138, 0)`** — the visibility setter on `self+0x138`, not
   a "shared setup" helper.
3. **0x0029126C is a visibility/flag setter**: `self->f_14 = flag; if (self->f_4 && self->f_4->f_10)
   self->f_4->f_10->f_44 = (old & ~1) | flag`. It is a mid-function split inside
   `Ui_Widget_ReleaseSub` (0x00291220), which is why `fn.py` reports it as a callee of
   `Ui_Widget_ReleaseSub`.
4. **0x0064DB08 is `return *(u8*)arg == 3`** (one `ldrb` + `cmp/moveq/movne`).
5. **0x005F34F0 is the 2D position setter** (`ldm r1,{r1,r2}; b 0x5F3500` →
   `str r1,[r0,#0x78]; str r2,[r0,#0x7c]`).
6. **0x0062F028 returns the child's `s8` at `+4`; 0x0062F038 invokes the child's vtable slot +8**
   when `self->f_140 != 0`.
7. **`Ui_TextListWindow_StepItemRects(self, delta)` treats `delta` as a direction**: `delta == 0`
   → `-1`, otherwise `+1`. Any caller passing 0/1 is a down/up pair.
8. **`asm/text` has bogus `.thumb` directives** (e.g. at 0x0024969C) that misalign the listing for
   the following ARM code. When the bytes look like two nonsense Thumb instructions, re-read them
   as one ARM word (`1040 2de9` = `push {r4,lr}`).
9. **`fn.py` only indexes `decomp/readable/functions/`**, so functions whose readable file lives in
   `decomp/readable/recovered/` report "no readable file found". `decomp/functions_index.json`
   (address → Ghidra file) is the fast way to read the pseudocode of an unnamed callee.
