## Method (what actually produced the evidence)

1. The pre-baked dossier for all 50 functions, read in chunks of ~10.
2. `symbols.json` (18,804 rows) as the name source instead of `tools/fn.py`, because `fn.py` only
   reads `decomp/readable/functions/` and ~800 named functions have no file there — including
   several callees I needed (`Ui_ListView_BindDataSource`, `Ui_Transition_Dtor`, `ToD`).
3. **The decisive step: resolve each batch address to the rodata/data word that points at it, then
   dump the surrounding table.** A function that is a vtable slot inherits the class of its
   neighbours, and that converted most class guesses into facts. `out/scratch/R3_053/ref.py` does
   the lookup, `near.py` / `vt.py` dump the table with current names.
4. `asm/text/text_XXXX0048.s` (block = `addr & ~0x3FFFF`, file suffix `+0x48`) for the four rows
   whose readable path is `decomp/readable/recovered/` — that directory is empty.
