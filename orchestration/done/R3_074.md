Every caller/callee list was treated as a hint and checked against the body.
2. **The readable tree was being regenerated while this batch ran.** At 18:51 `decomp/readable/functions/` held 2,791 files and the batch's own paths did not exist; by 18:54 it held 17,994. I used the pre-baked dossier for the bodies and re-read the files only after the tree settled. If a later worker sees different bodies, the dossier snapshot is the one this batch was decided on.
