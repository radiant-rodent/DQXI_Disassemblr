## Notes on decisions

* Confirmations stay at 0.5 and only where a named caller/callee (or an installed vtable symbol)
  pins both the role **and** the subsystem: e.g. `Ui_SlotTable_*` (three functions corroborating one
  ten-pair table), `Model_Attach_SetSpinRange` (twin fade setter), `Field_Action_ToggleRun`
  (named `SetRunState`/`InitHorseParams`/`Run_CheckCanContinue` callees).
* Kept `maybe_` where only the body is readable but the owning class is not (most `Field_Gimmick_*`,
  `Ui_Widget_*`, the four `Container_AddMaskedEntry*` siblings, the `Ui_DungeonHpWindow_*` pair whose
  class name is circular between the two functions).
* `0x003DA8A4` (`Ui_SlotTable_AddEntryEx`): the slot logic is clear but its callers are
  `SetScenarioWeather` / `Event_ApplyScenarioJumpSettings` and the sprite object is the Field2D
  manager at `(work+8)+0x88`, so the `Ui_SlotTable` label is suspect - kept `maybe_` with that noted.
