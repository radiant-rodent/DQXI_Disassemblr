# R_034 — second naming pass (refine), 147 low-confidence `maybe_` functions

## What was done

All **147** addresses in `orchestration/naming/refine/batches/R_034.txt` were re-examined and written to
`orchestration/naming/refine/out/R_034.json` (one object per address, batch order, 147/147 covered).

**Result: 62 `confirmed` / 40 `corrected` / 45 `kept_maybe`; confidence 0.30–0.60 (average 0.463).**
`python tools/check_refine.py R_034` → `R_034: OK`.

Files changed: `orchestration/naming/refine/out/R_034.json`, `AGENT_LOG.md`, this report. Scratch
(context-pack generator, JSON builder/validator, collision check) is in `out/scratch/R_034/`. No readable
C, symbols or tools were modified.

Method per entry: start from the doc header (previous name / confidence / evidence), then re-read the body
against the call sites the merge has now named. The batch's context score points at confident
callers/callees, but the decisive evidence usually came from (a) a named callee that turned the guess into
a subsystem fact, (b) a byte-identical twin whose class was already named, or (c) a caller showing that the
argument was not what the name assumed. Where only the meaning of a struct field was guessed the entry
stayed `maybe_` — a confident wrong name is worse than an honest `maybe_`.

The JSON was generated from one table and validated: every address exactly once, `previous_name` /
`previous_confidence` identical to the batch file, `change` semantics and the `maybe_` prefix rules checked,
signature function name equal to `name`, UTF-8 strict decode, no duplicate names inside the batch and no
collision with `functions_merged.jsonl` or any earlier `orchestration/naming/**` output.

## Name collisions handled

`Ui_System_Shutdown`, `Ui_TalkWindow_Dtor` and `Ui_ListWindow_Dtor` already exist at 0x00626E44 /
0x002187D0 / 0x0029F240. The three new functions were therefore named `Ui_GlobalObjects_Shutdown`
(0x001C5C14 — it tears down the global UI support objects, while 0x00626E44 is the audio/system one),
`Ui_TalkWindow_DtorB` and `Ui_ListWindow_DtorB` (B suffix = existing convention for twins).
