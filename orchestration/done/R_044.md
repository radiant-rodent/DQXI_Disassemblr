## Method

1. Doc header of each readable file (previous name/confidence/evidence) first.
2. Body re-read against the *current* callee names (the post-`M1_merge_names` readable C).
3. For every target, a scan of all `decomp/readable/**/*.c` files that mention its name, to get
   callers and callees; then targeted `grep` of the important call sites to make sure the "named caller"
   claim in the evidence is a real call and not a comment match.
4. Cross-checks: `orchestration/naming/refine/scores.jsonl` (`neighbour_names`, vtable cluster),
   `symbols.json` / `symbols_recovered.json` for name collisions, and the FACTS.md rules (getter trap,
   item ids 0..0xB3A / 0xB3B, bag size).
