## Method

1. Read README.md, orchestration/PLAN.md, REFINE_TEMPLATE.md, FACTS.md and `tools/check_refine.py`
   (the checker's exact rules, so the output cannot be sent back on a formatting technicality).
2. Built one index over all `decomp/readable/**/*.c` in `out/scratch/R_047/ctx.py`: address → readable
   file, header confidence, callee names, reverse caller edges. That let every function be read *with*
   its named callees/callers instead of grepping by hand 150 times.
3. For each address: doc header first (previous name/confidence/evidence), then the body against the
   current callee names, then `scores.jsonl` (`neighbour_names`, vtable cluster) and
   `symbols_recovered.json` for name collisions. Where a vtable slot mattered, the neighbour names of
   the same cluster were used as the evidence (they are quoted in the doc headers).
4. Saved progress in three part files and merged (`out/scratch/R_047/merge.py`), so a resumed worker
   would not redo finished work.
