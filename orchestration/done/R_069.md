## What this batch is

This batch covers a collection of middle-to-late engine and middleware functions:
1. **CECD Service & Icon Cache / File Object**: `0x006586D4..0x00658928` sitting in vtables `0x00780FC4` and `0x00780FF0` for raw-file write, delete, and dispatch retries.
2. **UI & Window System**: List model height recalc (`0x00640168`), panel show state (`0x00640514`), icon list idle check (`0x00641BA4`), list widget cursor reading (`0x006484EC`), sprite quad vertex colors (`0x00646400`, `0x0064663C`, `0x006470CC`), sprite pane frame updates (`0x00654EF0`), and scene flow state (`0x0066A8E8`).
3. **Field & Conditions**: Object and condition handle-group resolvers (`0x00640AC0`, `0x00649AAC`), player interaction gates (`0x00654F34`), and 2D field object screen rect calculators (`0x00667BE4..0x0066D9FC`).
4. **Data Tables & Records**: Senreki (Battle Record) callback dispatcher (`0x00644CA8`), smithing recipe attribute bitmask query (`0x006447D0`), spell record flags (`0x006494B0`), and skill sort priority comparison (`0x00666EA0`).
5. **Sound Engine & CWAV**: Wave info header parsing (`0x006605B4`), channel data offset calculation (`0x00660A38`), sequence field tag accessors (`0x0065EC70..0x0065ED9C`), and sequence parameter accessors (`0x00660AF8`, `0x00660C30`).
6. **CTR SDK Service Object Handling**: Object factory and handle assertion getters (`0x00655710`, `0x00655758`).
