## 2. Key Findings and Corrections

### 2.1 Group 1: Actor/Field Event & Component Handlers (`0x0066DA64`..`0x0066F608`)
The first group comprises actor event handlers and field object component methods that were previously mislabeled with `Ui_` prefixes during initial bulk passes.

- **`0x0066DD30`**: `maybe_Ui_Object_OnShow` -> **`Actor_OnMarkerShow`** (`corrected`, confidence 0.60).
  - *Previous error*: Assumed to be a UI object display handler.
  - *Correction evidence*: The function takes a component pointer where `component - 0x22C` is the `Actor` base object. It calls `Field_Marker_IsAnyVisible` (0x0047B470) on the actor, and if visible, triggers `Field_Object_PlayDefaultAnim(actor, 1)` (0x00364014). This is an actor marker visibility listener, completely unrelated to UI.
- **`0x0066DD5C`**: `maybe_Ui_Object_OnEvent_CompareName` -> **`Actor_OnEventCompareActionName`** (`corrected`, confidence 0.55).
  - *Previous error*: Assumed to be a UI event string comparator.
  - *Correction evidence*: Calls `func_00590504(1)` which resolves table entry 1 (`"Act_01"` at `0x007896A0` in `data_007AB000.s`), and compares it against the actor's current action string via `strcmp` (`0x0010540C`). Operates on the actor component at `self - 0x174`.
- **`0x0066DDC8`**: `maybe_Ui_Object_OnEventWithTransform` -> **`Actor_OnEventForwardWithChildToggle`** (`corrected`, confidence 0.55).
  - *Previous error*: Vague UI event transform name.
  - *Correction evidence*: Calls `0x0028E548` (disassembly identical to `0x0066DC74`), which receives `(actor, eventId)` and toggles the sub-object at `actor + 0x4C` for events 2 (enable) and 3 (disable), before forwarding the event to the delegate listener at `self->f_6c` via virtual method `+0x18`.
- **`0x0066DF60`**: `maybe_Ui_Object_OnEventToggleVisibleC` -> **`Actor_OnEventToggleVisibleC`** (`corrected`, confidence 0.55).
  - *Previous error*: Mislabeled as UI object.
  - *Correction evidence*: Handles event 2 (enable sub-object at `self - 0x1E0`) and event 3 (disable sub-object, clear timer byte `+0x5C`, and stop effect `self->f_8c` via `func_0029E380`). Component base matches `0x0066DC74`.
- **`0x0066E7B4`**: `maybe_Field_Object_OnSoundTrigger` -> **`Field_Object_OnTriggerRangeUnlink`** (`corrected`, confidence 0.55).
  - *Previous error*: Mislabeled as sound trigger because the previous pass mistook `0x0011FCB0` for a sound playback routine.
  - *Correction evidence*: Disassembly of `0x0011FCB0` reveals it is an intrusive doubly-linked list node unlinker (`str r3, [r0, #4]; str r0, [r3]; sub count, 1; str ip, [r1]`). When `self->f_20` falls in `[low, high]`, the function unlinks `&self->f_c` from the container's active update list and resets pending flags.
- **`0x0066DD10`**: `Actor_HandleFlagEvent` (`confirmed`, confidence 0.50). Confirmed callee `Field_Object_PlayDefaultAnim` (0x00364014) on `component - 0x22C`.
- **`0x0066E0D8`, 0x0066E18C, 0x0066E224`**: `Field_Object_BindModelTransformB/C/D` (`confirmed`, confidence 0.50). Template copies in vtables `0x00769CB4`, `0x00772F64`, and `0x00775310` binding model matrix offsets.
- **`0x0066E820`**: `Field_Object_UpdateAttachedEffects` (`confirmed`, confidence 0.50). Dispatches up to 4 attached effect descriptors via `0x005493A0`.
