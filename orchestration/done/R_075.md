# R_075 — second naming pass (refine)

## What was done

Processed all **148** low-confidence `maybe_` functions in `orchestration/naming/refine/batches/R_075.txt`
(addresses `0x00341394`–`0x0037B224`) and wrote `orchestration/naming/refine/out/R_075.json`.

For each function:
1. Read the readable C decompilation, documentation header, previous name, confidence, and evidence.
2. Cross-referenced callers across all readable C files and symbols in `symbols.json`.
3. Checked class vtables and descriptors in `rodata_00765000.s`.
4. Verified algorithms and established facts in `orchestration/naming/FACTS.md`.
5. Decided `confirmed`, `corrected`, or `kept_maybe` and recorded concrete new evidence.

**Result**: 3 `confirmed` (2.0%), 1 `corrected` (0.7%), 144 `kept_maybe` (97.3%).
Confidence range: 0.20–0.65. Confidences of 0.50 and above were strictly reserved for functions with caller/vtable/algorithmic proof; damaged bodies, interior blocks, and ambiguous slots keep the `maybe_` prefix with confidence < 0.50.
