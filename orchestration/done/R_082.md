## 2. Key Findings & Detailed Group Breakdown

### 2.1 Key Correction: Skill Sort vs Glyph Metric
- `0x0071F514`: `maybe_Ui_SortEntriesByGlyphMetric` -> **`Skill_SortSkillIds`** (`corrected`, confidence 0.65).
  - *The Initial Error*: In the first pass (`N_077`), the author mistook record accessor `0x0018C1B8` for a font glyph metric lookup, guessing that the caller was sorting UI table rows by text width.
  - *Context & Established Facts*: ESTABLISHED FACTS confirm that `0x0018C1B8` is the master `SkillRecord` lookup wrapper (`0x0063D018`, stride `0x100`, 191 skills). The comparator called by `0x0071F514` (`0x00666EA0`) was confirmed in `R_069` as `Skill_CompareSortPriority`, comparing `SkillRecord->u16_c2` sort priority. The function is a full introsort (median-of-three partition, insertion sort for small partitions, heapsort fallback when recursion depth reaches 0) sorting a list of byte skill IDs by game sort priority.
