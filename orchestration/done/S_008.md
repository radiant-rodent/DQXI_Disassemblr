8. **Battle_Manager** (size: 4708, base: `Ui_BattleTargetMarker`, 16 fields):
   Battle state machine controller driving target marker updates, command selection state (0xFFB..0x1020), active actor context, and child command windows.
9. **Battle_ActionAnimTable** (size: 628, base: `Battle_Action`, 10 fields):
   Battle action animation table managing character action animator slots, weapon equip models (`Model_Equip*`), and scene containers.
10. **Battle_PopupEntry** (size: 464, vtable: `0x0075E91C`, 13 fields):

11. **Battle_ActionAnimEntry** (size: 76, 11 fields):
