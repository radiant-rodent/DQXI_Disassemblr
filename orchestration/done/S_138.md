recovered function of the 15 classes plus the helpers they call, via `tools/fn.py` dossiers

## Open problems / not verified

* Every `maybe_*`/`unknown_*` field.
* `Ui_MessageQueue`: the head words at +4/+8 and whether +0xF4 is a terminator or an unused slot.
* `Ui_MessageStyle`: whether 12740 bytes is the whole message window or a slice whose two trailing
  bytes belong to it.
* `Ui_ResourceTree` +0xB4/+0x304: embedded node context vs container (callee signature damaged).
* `Ui_ResourceCache`: +0 vs +4 list-head layout; node size 0x90 (Insert) vs 0x9C (CreateEntry).
* `Ui_PanePair`: the two animation names at DAT_003190E8 / DAT_003190EC were not decoded.
* `Ui_ObjectBase` / `Ui_ObjectDesc` / `Ui_Result` / `Ui_RowListOwner` / `Ui_MessageStyle` keep
  batch class labels that do not match their real families (battle action sub-object, UI object
  base, equip row, time display window, message window).
