## Naming approach

- Roles taken from the hint / calls / fields / consts columns and the printed bodies.
- Stack blocks passed to init/factory calls named by their role (`meshSetup*`, `spriteArg*`,
  `weaponSetup*`, `spawnArg*`, `itemSetup*`), keeping the original field offsets in the name where the
  block layout is the only fact available.
- Register-reuse artifacts (`extraout_r1*`) named `maybe_extraReturn*`.
- Entries whose roles could not be pinned down (0-1, 0-5, 0-6, 0-25) were given confidence < 0.5 and
  every name in those entries is `maybe_`-prefixed, as required.
