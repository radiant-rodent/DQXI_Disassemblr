## Variables named

About 670 names in total, roughly 640 locals plus 30 parameters. Naming conventions used:

- loop counters and indices: `index`-style names (`rowIndex`, `lineIndex`, `cellIndex`, `i`, `segmentIndex`) or `digitChar`/`isNineFlag` for the digit-increment idiom that repeats in nearly every pane initialiser.
- stack name buffers: `txtNameHead` / `txtNameDigits` / `txtNameDigit` / `txtNameTerm`, and `leftName*` / `rightName*` / `centerName*` / `nullNameWordN` / `iconNameWordN` for the multi-column variants.
- child descriptors (`Gfx_SpriteActor_AddChildC` blocks): `childType`, `childFlags`, `childCategory`, `scaleX/Y/Z`, `quadParam0..5`, `colorWord0..2`, `colAnimParams`, `colAnimFieldN`.
- sprite/quad entries submitted to the scene: `entryX/Y/Z`, `entryFlags`, `entryParam`, `rectPtr`, `spriteCtxPtr`, `worldX/Y`.
- matrix/quaternion temporaries: `matWord0..3`, `quatWord0..3`, `vecX/Y/Z`, `axis2X..W`, `axis3X..W`, `quatOutX..Z`.
- allocator/list plumbing: `listNode`, `keyframePtr`, `timelineEntry`, `resourceSlot`, `heapTag`, `allocParams`, `maskValue`, `zeroVector`, `zeroValue`.
- object/ctor returns and vtables: `objectPtr`, `elementPtr`, `actionPtr`, `modelObj`, `tableVtable`, `drawListPtr`, `dataBlockPtr`.
- allocated effect pools: `entryCtor` for the state-sequence ctor pointer, `defaultFade` for the reused default-block word.
- name tables and descriptors: `descriptorTable`, `descriptorPtr`, `rowTypes0/1`, `nameBuf`, `nameHead`, `nameDigits`, `nameTail`.

Per-entry confidence was recorded with each answer: 0.85 for the straight vtable-installing constructors,
0.6–0.7 for the pane initialisers and list/allocator helpers, 0.5 for the heavily reused register temporaries
and the damaged bodies (mesh-emitter setups, helix/sphere transforms, `Model_AttachAnimationByHandle`,
`Ui_TenRowModePanes_Setup`).
