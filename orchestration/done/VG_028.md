## Naming conventions used

- Loop counters/cursors: `index`, `i`, `slotCursor`, `attemptCount`, `patchPos`.
- Stack words passed to `Os_GetGameWork`/`Game_GetWork`: `scratchWord`, `workBuf`, `idBuf`.
- Return values kept in temps: `result`, `checkResult`, `stepResult`, `moveResult`, `callResult`.
- Descriptor/instruction buffers in the compiler functions: `instrBuf`, `opCode`, `destOperand`,
  `srcOperand`, `auxOperand`, `subOp`.
- Unread PARAM rows: `unusedArg`, `unusedArg2`, `unusedArg3`.
- Register leftovers / damaged decompilation (`extraout_r1`, `unaff_r*`, `in_cr*`, `in_s*`, `in_d9`):
  `spillR1`, `preservedR6/R7/R8/R9`, `cr0Value/cr6Value/cr9Value`, `stackValue`, `heightOffset`.
