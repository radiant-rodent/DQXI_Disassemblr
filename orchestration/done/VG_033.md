  `styleRate`, `styleSpread`, `styleWidth/Height`, `styleFlagN`, `styleIdA/B/C`, `styleAlphaMax`.
- `Script_Vm_RegisterDefaultDelegates`: long alternating pattern named `objValue0..32` (tagged Squirrel
  value word pushed to the vector/hash set) and `slotPtr0..30` (its `(*vm+4)-1` companion slot).
- Script callback bodies (`CallBookIdCommand`, `CallEventHandlers`, `CallSelectRuraPattern`,
  `CallSelectRiremitoUsable`): `valueWord0..2`, `objectType`, `contextPtr`, `vmArgPtr`, `stringPtr`,
  `errorTextBuf`, `errorOwnerPtr` for the Squirrel stack/error-record temporaries.
- Load-screen state steps all end up with `stepResult` (readiness + transition request) or `widgetPtr`
  (the `self+0x918` widget reused for the result).
- Uninitialised / stale register artefacts: `uninitReg`, `staleWord`, `uninitObj`, `uninitWord0/1`,
  `crNValue`, `inReg12`, `staleReg` (these have no writer in the decompiled body).
