## Variables named

Every row in the "variables still to name" table of every function was named - parameters as well as
locals. Names follow the body plus the "hint"/"calls"/"fields"/"consts" columns, and the naming
conventions already used by the first pass:

- state-step temps: `isReady`, `widgetPtr`, `menuStatus`, `stepStatus`, `anchorPtr`;
- record/candidate pointers: `candidatePtr`, `recordPtr`, `unitRecordPtr`, `tacticRecord`,
  `classNodePtr`, `listHeadPtr`, `listNodePtr`, `prevNode`/`nextNode`;
- pool/bit-mask machinery: `isFirstPool`, `stateValue`, `bitIndex`, `maskValue`, `pairIndex`;
- stack descriptors: `maybe_ctxCopyXX`, `maybe_rowWordXX`, `maybe_rowByteXX`, `popupArg`,
  `popupArgPtr`, `workBuf*`, `gameWorkBuf`, `defaultParamsPtr`;
- unused parameters were still named (`unusedArg2/3/4`, `styleArgUnused`, `flagArgUnused`,
  `workBufSeed`) because the ABI keeps them and the tool lists them.

No name from the per-function "already used names" note was reused, and no function has two
variables with the same name.

## What was left out and why

Nothing. The only entries with reduced confidence are the ones whose evidence is genuinely weak, and
those follow the rule "below 0.5 -> every name of that entry gets the `maybe_` prefix":

- truncated `halt_baddata` stubs and split-function artifacts: `Ui_LoadScreen` dispatch callback
  (0.3), `maybe_Ui_BattleCmd_Noop` (0.3), `maybe_Ui_Window_FinalizeK` (0.4),
  `maybe_Ui_Window_AdvanceScriptCmd06B` (0.4), `maybe_Ui_BattleWindow_HideTargetWindow` (0.35);
- damaged branchy handlers: `Ui_BattleTargetWindow_Init`, `Ui_BattleWindow_CloseAllPanes`,
  `Ui_BattleCmd_HandleConfirm`/`HandleCancel`, `Ui_PartyPanel_*` handlers (0.35-0.4);
- functions whose listing was cut by the 500-line / output limit (`maybe_Ui_TextLayout_LayoutMode6`
  with its ~110 zero-initialised row-struct words, `Ui_TextLayout_LayoutRowsForMode`,
  `Ui_RecipeBook_EvaluateRecipeQuery`, `Ui_TextLayout_FillSlots`, `…FillSlotsByGroup`), where the
  visible body plus the hint columns still fixed the role of every row but not always a strong
  domain name (0.4-0.45);
- parameters that never appear in the body (`arg2`/`arg3`/`arg5` of several window constructors and
  cmd handlers): named as `unusedArgN`, prefixed `maybe_` when the entry confidence is below 0.5.
