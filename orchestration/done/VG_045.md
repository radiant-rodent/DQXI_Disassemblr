## Naming approach

Names follow the bodies, the hint/calls/consts columns and the surrounding named members:

- Action-state locals are `stateOffset` / `stepId` (compared against a base id) and the copied
  state value is written back through `actionStatePtr` / `stateCallback`.
- Battle-local structures built from the action row before a UI call are named as parameter blocks:
  `popupParamA/B/C`, `messageWord1..11`, `messageByte1..6`, `effectParam*`, `dirVecX/Y/Z`.
- Model/world math locals are `spinePosX/Y/Z`, `jawPosX/Y/Z`, `targetPosX/Y/Z`, `refDirX/Y/Z`,
  `angle*`, `vecBufX/Y/Z`, `crossVecX/Y/Z`.
- Copies of parameters kept on the stack are named after the parameter (`stepValue`,
  `visibilityMode`, `actorSelf`, `firstSlotCopy`).
- Constants loaded into locals are `zeroFloat` / `oneFloat` / `dirThreshold` / `angleLimit`.
