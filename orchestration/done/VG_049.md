  `labelIdA/B/C` for the three text-segment ids passed to `func_0048FC6C`.

  two callees became `updateArg`, the game-work frame parameter became `workFrameArg`.
* Struct-like stack blocks were named field-by-field with a common prefix:
  `targetRecord*` (target descriptor built in maybe_Text_FindRowIndexByType), `rowRec*` / `params*`
  (local row record in the message-row layout builder), `placement*` (placement copy in
  Field_ActorGroup_ApplyFormation), `fcol*` (Gfx_CreateFColAnimator block), `slot*` / `subFlag*` /
  `tailFlag*` (unit-parameter block in Field_BattleTrigger_StartBattle), `paramField*` (block header
  bytes), `argField*` (func_0011142C argument record), and `*_` suffix-free `valueXX`/`flagXX`
  names for the remaining fixed-value descriptor bytes.
* Constant roles were named from their values: `zeroConst`, `oneValue`, `unitScale`,
  `percentScale` (0.01), `epsilonConst` (2^-16), `halfConst`, `circleSpan` (2π), `invTwoPi`,
  `degToRad`/`angleValue`.
