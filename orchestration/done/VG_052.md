## Naming approach

* Loop counters and base indices: `index`-style names (`triBaseIndex`, `loopCount`, `savedIndex`).
* Pointers to records read for one or two fields: `entryPtr`-style names
  (`glyphCellPtr`, `metricRowPtr`, `matPtr`, `scalarPtr`).
* Stack buffers passed to a call: `buf`-style names (`u16Buf`, `floatBuf`, `refCopy*`, `sectionPtr1..5`).
* Return values kept in a temp: `result`/`status`-style names (`tmpResult`, `calcStatus`, `lookupResult`).
* Constants copied into registers: `*Bits`/`*Const` names (`fixedScaleBits`, `tenFloatBits`, `scaleConst`, `oneConst`).
* The 8-corner frustum block in `Camera_BuildFrustum` was named `corner0X..corner7Z` from the
  12-byte stride and the `func_0055A30C(...,8)` call.
