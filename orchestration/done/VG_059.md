- Return values kept in a temp: `result`/`status`/`tempValue`; heavily reused
  temporaries that change meaning mid-function: `recordPtr`/`tempValue`.

  `func_0011FE8C`/`func_0011CFAC`/`func_00116AE0` allocation chain).

  `headerField74`, `recordFieldNN`, `defaultParamNN`, `nameWordN`, `copyWordN`,
