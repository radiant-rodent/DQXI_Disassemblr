# V_059 - local-variable naming batch

## What was done

Worked through all 150 functions in `orchestration/types/batches/V_059.json` using
`python tools/batchview.py V_059 next` / `--add` only, then ran `--check` (150 answers,
0 problems).

- 150 functions answered in `orchestration/types/out/V_059.json`
- 799 names total: 7 parameters (remaining `argN`/placeholder params) and 792 locals
- 1 name carries `maybe_` (a register that holds two different roles in
  `maybe_Ui_StatusParamWindow_ToggleMemberRow`)
- 24 functions have empty rename maps: constructors/destructors whose only token is
  `self`, or functions that take just `self`

Names were derived from the merged field/global names, callee names, vtable slots,
string literals, constants and the visible body. Typical results: constructor
`object`/`vtable`, popup spawners `popupEntry`/`windowDescriptor`/`popupVtable`/
`uiMode`, battle action UI `rowObject`/`statePtr`/`uiContext`, party panel
`memberRecord`/`memberId`/`partyIdList`, slot/payout gauge `rangeValue`/
`segmentValue`, effect spawners `cachedHandle`/`transformDesc`/`effectHandle`.

## Skipped / left unnamed (and why)

- Entire functions omitted (recorded by the tool as reviewed, nothing clear):
  - `0x003F463C` / `0x003F5528` (Update2D/3D) and `0x003F6208` / `0x003F643C`
    (their continuation fragments): bodies truncated by the output limit and full of
    damaged registers / `halt_baddata`, so most locals would be guesses.
  - `0x00403184` party-panel cursor init: `arg3..arg5` are opaque context words with no
    visible meaning.
  - `0x00403008` HP-gauge composite dtor and `0x0040673C` fixed-array destroy: only
    already-descriptive tokens.
- Inside large/truncated functions only the clearly justified tokens were named; float
  math scratch, packed message-struct words, `CONCAT*` temporaries, stack out-buffers
  for `Game_GetWork`/`Os_GetGameWork` and reused registers (one token holding two
  unrelated roles) were intentionally left alone. Examples: the 775-line
  `maybe_Battle_ActionUi_Update`, the aura/focus-point transform builders, and the
  `Ui_SlotWindow_UpdatePayoutAnim` tail.
- Every name that could not be justified from the body/calls/fields was dropped rather
  than invented; no readable C or headers were modified.
