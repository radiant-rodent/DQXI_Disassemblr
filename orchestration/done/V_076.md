## Style used

- Loop counters over slots/entries were named for the counted thing (`slotIndex`, `entryIndex`,
  `partyIndex`); only pure index loops got `i`.
- Repeated idioms got consistent names across siblings: `gameWork`/`workBuffer` for
  `Os_GetGameWork` results, `handleEntry`/`handle` for the packed-handle table lookups,
  `stateValue`/`isIdle` for the `+0x78 < 4` liveness tests, `halfFrame`/`frameDelta`/`deltaValue`
  for the five message-voice line functions, `spriteEntry`/`modelMemory`/`templateRecord` for the
  two Field_SpriteActor setup functions.
- Confidence was lowered (0.5) where only the surrounding call shape justified a name; the
  evidence field records the concrete anchor (callee, field offset, global, constant, string).
