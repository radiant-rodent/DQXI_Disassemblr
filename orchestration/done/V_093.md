## Recurring naming decisions

- Command-buffer write pointers: `cmdPtr` (raw `*writePtrSlot`) and `writePtrSlot` (`(int *)(cmdbuf + 4)`)
  for the ubiquitous `Gfx_MaterialState_*` / `Gfx_GpuCmd_*` patterns.
- Per-part 0x2c-stride entries `partEntry`, 0x158-stride state blocks `stateBlock`, cached
  `{id, short, short}` records `cachedState`, their comparison `stateMatches` (shared by
  `Gfx_ModelInstance_WriteMeshCommands`, `Gfx_CharModel_DrawPart`, `Gfx_SceneObject_DrawParts`).
- `func_0063FA60` results `moveRecord`/`charRecord`, `func_0063FC70` results `entryRecord`,
  `Game_GetDataManager` results `dataManager`, actor (`vtable +0x3c`) results `actor`, `f_274` values
  `charId` across the Battle2DUnit family.
- Screen-space pass matrices: `quadMatrix` (`func_006F2D98` result), 1.0f/-1.0f literal triples left alone.
- Sprite/set code: `recordPtr`/`recordEnd` for the 0x3c-stride array cursors, `spriteName` for the
  `-1`-tested name byte, `symbol`-free `tmpRecord` for `func_00576BA8` staging.
- 4x3 transform decomposition blocks (`func_00572EC4`): `decompMatrix`; transformed boxes from
  `Gfx_Bounds_CalcTransformedBox`: `boundsBox` (identical in `Gfx_Sprite_*` and `Gfx_SceneNode_*` twins).
- `Gfx_Resource_FindSizeRecord`/`Gfx_Palette`-style table lookups: output u16 slots `widthOut`/`heightOut`,
  shared table rows `tableEntry`.

## Deliberately left unnamed (with the reason recorded in `evidence`)

- Matrix/vector shuffle temporaries (`uVar1..uVar8` in `Gfx_CmdBuf_SetMatrixBlock`, `uVar3..uVar8` in the
  sprite/node transform setters, the whole `local_d8..local_9c` block in
  `maybe_Gfx_CharModel_UpdateProjMatrices`): each register is reloaded with a different matrix word
  before use, so no stable per-variable meaning exists.
- Broken / truncated decompilations with no readable C or with >100 "unreachable block" warnings and only
  stack scratch (`maybe_Model_SecondaryMotion_BuildChains`, `maybe_Gfx_CmdBuf_WriteColorCommands`,
  `maybe_Gfx_ResourcePool_Purge`, `maybe_Gfx_SpriteSet_InitBaseFromBank`,
  `Gfx_ModelInstance_DrawFullscreenQuadPass` partly, `maybe_std_InitStaticArray`).
- PICA state descriptor staging blocks (`local_a1`, `local_d4`, ... in the blend/colour writers) where every
  byte is an independent literal with no documented meaning.
- Parameters that are never read (`arg1` in `Gfx_CmdBuf_WriteStateTemplate`, `arg2` in
  `maybe_Gfx_CmdBuf_BuildRampParams`, `arg3` in the `Field_Gimmick_SetDataPtr` / Battle2DUnit slot
  functions) were left as-is rather than given invented names.
- `self` was kept wherever the C already used `self`; it was only renamed to `unit` / `entry` / `state` /
  `object` where the readable C itself used that noun and the object identity was provable from field use.
