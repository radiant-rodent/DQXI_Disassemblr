# V_098

Named local variables and remaining `argN` parameters for batch V_098
(`orchestration/types/batches/V_098.json`), output written to
`orchestration/types/out/V_098.json`.

## Result

- 145 functions answered (the batch's 5 pre-named functions were kept as-is).
- 2 parameters renamed (`arg3` -> `cmdParam`, `arg4` -> `cmdParam`).
- 818 locals renamed.
- 5 names carry the `maybe_` prefix (low confidence).
- `python tools/batchview.py V_098 --check`: 145 answers, 0 problems.
- Batch output re-parsed as JSON successfully.

## What was renamed

- Squirrel VM natives (`Script_Vm_*`, `Script_Native_*`): the repeated
  `func_005B5C78`/`func_005B5C6C` tag/value slots became `objectSlot`, ref
  table fields became `refTable`/`slotCount`, and the native-binding wrappers
  got `paramCount`, `methodTable`, `errorState`, `errTypeBuf`, `errMsgBuf`,
  plus a specific id name per binding (`cutsceneId`, `questId`, `areaId`,
  `scenarioBattleId`, `panelId`, `skillId`, `spellId`, ...), justified by the
  type-descriptor globals and validation constants.
- Graphics command-buffer writers (`Gfx_CmdBuf_*`, `Gfx_Pica_*`): `cmdPtr`,
  `writePtr`, `drawNode`, `stateNode`, `textureNode`, and one payload name per
  parameter (`cmdParam`).
- AABB/matrix/bone helpers: node/transform table walkers (`nodeTable`,
  `transformTable`, `childIndex`, `nodeFlags`), arc-length table build
  (`totalLength`, `pointB..pointD`, `nodeOffset`), and the UI widget draw
  passes (`layerStatePtr`, `savedTransformFlags`, `layerValue`).

## Skipped / left unnamed

- Three functions were recorded as "reviewed, nothing clear" with empty maps:
  - `Os_FlushBufferToPhysical` (0x00679544): its only variable was already a
    descriptive name from the rule pass.
  - `maybe_Container_InitPair32` (0x00680780): only already-named `self`/`id`
    parameters.
  - `Math_Matrix44_MultiplyDirect` (0x006F00C8): the decompiled body is a long
    sequence of VFP flag/register manipulation whose operands could not be
    tied to a single meaning.
- Inside otherwise-named functions, VFP status-register temporaries, single-use
  scalar copies of matrix elements, and tokens reused for two different
  quantities in the same body were deliberately left unnamed (documented per
  function in the `evidence` field).
- All raw PICA200 command register byte literals and stack-spill copies of
  relocations were left alone.
