## Decisions

Repeating stub shape -> consistent vocabulary, so the merged C reads uniformly:

- `func_006BBD6C()` compared to a small constant -> `argCount` (script stack slot count).
- `func_005766A4()` (byte flag + VM pointer at +4) -> `errorState`; when a function fetches it twice
  the second token is `errorSlot` to avoid a duplicate name in one function.
- out param of `Script_Vm_GetUserPointer`, later called as a code pointer -> `userPointerPtr`.
- the 4-byte stack head passed to `Script_GetIntegerArg`/`Script_GetIntArg`/`Script_Format*Error`
  -> `argValueBuf`, `firstArgBuf`, `secondArgBuf` or `errorValueBuf` depending on its dominant use in
  that function; the adjacent 128-byte buffer thrown to `Script_Vm_ThrowError` -> `errorMessageBuf`.
- the checked argument is named from the embedded `g_scriptTypeDesc*` and the bound: e.g.
  `g_scriptTypeDescItemID` + `0xB3B` -> `itemId`, `g_scriptTypeDescPlayerID` + `0x1E` -> `playerId`,
  `g_scriptTypeDescLevelMapID` -> `mapId`.
- shared trampolines with unrelated aliases (e.g. `Script_Bind_PictureCardDisable` with 28 names,
  `Script_Bind_StopME`/`CameraZoom`) got deliberately vague slot-based names (`firstArgValue`,
  `argValueBuf`) instead of guessing one alias's meaning.
- string-marshalling stubs (slots read with `Sq_VmReadStackSlot` + `Script_Vm_GetString`): the
  `... = vm` locals that are only tested against 0 are `maybe_vmRef`/`maybe_...Guard` (conf 0.4),
  the string holders take the names from the documented signature (`threadName`/`labelName`,
  `titleText`/`messageText`/`confirmText`, `locatorName`, `gadgetName`/`boneName`).
- left alone on purpose: `vm`, `result`, and `scriptGetIntegerArg` where it was already a readable
  name, plus every token the rule pass had already named (`...integerArg`).

One self-inflicted issue, found and fixed: an accidental duplicate record for
`Script_Bind_ActorSetMouse` (0x00701510) overwrote that function's map in the out file; it was
re-added with the full local map and the file now holds exactly 150 unique addresses.
