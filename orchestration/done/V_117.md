Batch: `orchestration/types/batches/V_117.json` (149 functions).
Output: `orchestration/types/out/V_117.json` - 134 records, `--check` reports 0 problems.

## What was done

- 134 functions answered (the batch tool printed 134; the remaining 15 were already named by the
  rule pass and never shown).
- 71 functions received at least one name: 410 local variables and 4 `argN` parameters renamed.
- 63 functions were recorded as "reviewed, nothing clear" (empty `locals`/`params`).
- No name needed the `maybe_` prefix: every name I kept has confidence >= 0.5. Names I could not
  justify were left out instead of being guessed with a low confidence.

## Naming basis

Names come from the current readable C plus the merged field/global names, e.g.
`self->worldMatrix00`, `g_fieldObject2DDefaultVtable`, `Math_ComputePrincipalAxesQuaternion`,
`Fx_Billboard_EmitList`, `Actor_Action_ApplyFlagsAndState`. Recurring patterns:

- cross-product triples from `func_00575664` -> `normalX/Y/Z`, `crossBCX/Y/Z`, ...
- 12-float matrix blocks written by `func_0057609C` -> `basisMatrix0..11`, `chunkMatrix0..11`
- min/max accumulators seeded with `0x7F7FFFFF` / `0xFF7FFFFF` -> `minX/minY/minZ`, `maxX/maxY/maxZ`
- intrusive-list unlink pairs -> `nextNode` / `prevNode`, `childNode`, `entryCursor`
- `argN` parameters: only 4 could be justified (`arg2` -> `basePoint` in the two sphere builders,
  `arg5`/`arg6` -> `param5Value`/`param6Value` in `Gfx_SceneEntry_SetupFromDescriptor`).

## Skipped and why

- 63 functions with nothing to name: pure deleting destructors (`func_00200220`/`func_0010F6CC`
  only), one-line setters, and functions whose only variables are uninitialised register inputs
  (`in_r12`, `in_s0`, `in_cr*`, `unaff_r*`).
- Functions with no readable C and only decompiler garbage: `maybe_Script_CheckObjectTypeId`,
  `maybe_Gfx_Scene_GridMarkBits`, `maybe_Battle2DUnit_NotifyActionEvent`,
  `maybe_Field2D_Sprite_SetRecord`, `maybe_Field2D_Sprite_SetScaleAnim`,
  `maybe_Field2D_Sprite_SetAnimFromRecord`, `maybe_Field2D_Actor_SetFlag`,
  `maybe_Field2D_Scene_NotifyNearbyActor`, `maybe_Field2D_Sprite_IsActive`,
  `maybe_Ui_Widget_CompareFlag*`, `maybe_Ui_Widget_ClearFlagRecursive`,
  `maybe_Field2D_Step_BuildSoundParams`, `maybe_Field2D_Sprite_DrawSorted` (partly).
- Individual variables left unnamed inside otherwise-named functions, because the same token is
  reused for two unrelated values (e.g. `iVar1`/`iVar2`/`fVar14` in `Math_ComputeObbFromPoints`,
  `iVar1` in `Gfx_SceneEntry_BuildMesh`, `result` in `maybe_Ui_CheckCharaStateMatch`), or because
  the component order could not be established (`local_a0/9c/98/94` in
  `Gfx_Bounds_TransformPointsToObb`, `local_c4/b4/a4` in `Gfx_ModelInstance_ApplyEnvParams`).
- `Math_ComputePrincipalAxesQuaternion` was omitted entirely: its body is only float shuffle temps
  that are reassigned to different quaternion components depending on two branch flags.
