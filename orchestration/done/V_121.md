## Naming scheme used

The batch is almost entirely two families of boilerplate in the Dive field-actor library:

- `Field_InitActorColorTable_*` / `Field_InitActorColorTables_*` / `Field_InitActorParamBlock_*`
  — one-shot static initialisers of 12-entry RGBA palettes. `puVarN` holding the 48-byte palette
  became `colorTable`; the 4-byte all-`0xff` entry became `whiteColor`; `uVarN = (u8)alpha`
  became `alphaByte`; the `PTR_DAT_*`/`&g_actorColorTableInitState` guard tested with `& 1`
  became `initStateFlag`; the `0x3F2E40F1` block header became `headerWord`; the parameter
  block pointer `in_r3` became `paramBlock`.
- `Field_RegisterActorClass_*` — actor class registration. `classRecord` (self links at
  +0/+4/+8, class-name string at +0x10, parent at +0xc), `baseClass` / `parentClassRecord`,
  `registryInitFlag` (`&g_fieldActorRegistryInitializedFlag`), `registryHeadNode`
  (`&g_fieldActorRegistryHeadNode`), `registryNode` (the allocated node), `nodeSelfLink`
  (node+1), `listLink` (head+4, passed twice to `func_001235A4`).

Confidence is 0.5–0.6 throughout; no name needed the `maybe_` prefix.
