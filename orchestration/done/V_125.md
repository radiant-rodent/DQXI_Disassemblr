## Skipped and why

- `std_Delegate_Invoke5ArgsA/B/C/D/E/F`, `std_Delegate_Invoke6ArgsA/B` (8): pure arity-adaptor stubs whose
  whole body is `(*fn)(arg2..argN)`. `fn` is already named; the `argN` are generic forwarded values with no
  recoverable meaning, so any noun would be invented.
- `Field_SpriteElem_DestroyOwned30A/B/C`, `Field_SpriteElem_DestroyOwned38` (4): only parameter is `self`,
  no locals.
- `Field_Scene_InitElemE8`, `Field_Scene_InitElemDC`, `Field_Scene_FreeElemE8` (3): only parameter is
  `self`, no locals.

## Deliberate omissions inside answered functions

- `maybe_Container_List_AssignRangeNodes`: `puVar1` left unnamed. It is the destination node's forward link
  in the forward loop but the source range end / source cursor in the backward (overlapping) loop, so a
  single noun would be wrong for one of the two branches.
- `Sq_Stack_Destroy`: `i` left as `i` - it is a pure index into the 8-byte entry array.
