    Notes / counting rules

    • Named: the effective function name is no longer a decompiler/seed placeholder (FUN_, func_, sub_, thunk_, LAB_, maybe_, DAT_). A high-confidence naming proposal counts as named even before M1_merge_names.
    • Proposed: a naming proposal exists but the name is provisional (maybe_ prefix or confidence < 0.5), so it stays amber rather than blue.
    • Documented: the function carries a human summary — a summary field in functions_merged.jsonl, a naming-proposal summary of at least 20 characters, or a comment block in its readable C beyond the Ghidra export header. The generic "Regenerated by Ghidra" header does not count.
    • Matching C: only functions proven byte-identical by build/replacement_report.json (or the last audit/PROJECT_VERIFICATION.json snapshot). Readable Ghidra C is not matching C.
    • Data & types: worker answers in orchestration/types/out/{G,S,V}_*.json count as named when confidence ≥ 0.5 without a maybe_ prefix, and guessed when provisional (maybe_ or confidence < 0.5). Merged counts declarations and maps actually written to include/dqxi/*.h and orchestration/types/merged/ by M2_types_merge / M3_vars_merge.
    • Scripts: total = CNUT containers; decompiled = scripts_ok or live *.decompiled.nut; recompile-verified needs an explicit recompile manifest or *.recompiled.* output. Decompiling is not recompiling.
    • Assets: converted means a standard-format output exists, not that the asset is semantically complete (for example 4,779 of 10,542 BCH files yield meshes). Editable counts are capability counts for the write-back tools; tables stay at 0 until a general BXON writer exists.
    • Editor: checklist from progress/features.json, weighted done=1 / partial=0.5. It is a human judgement, not a test result.
    • Build health: parsed from build/ artifacts and audit reports. "Stale" means a previous run passed but the artifact/log is missing now.
    • Every number is regenerated from files on disk. Missing generated data shows zero or “not generated yet” rather than an error.
