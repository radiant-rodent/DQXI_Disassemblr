# DQXI Explorer & Level Editor (Rust)

Native egui/OpenGL project browser and editor for the data generated by the Python tools.

## Run

```powershell
cargo run --release
```

or from the project root:

```powershell
run_editor.bat      # opens the Level Editor section
run_viewer_rs.bat   # opens the project browser
```

Environment variables:

| Variable | Effect |
|---|---|
| `DQXI_PROJECT_ROOT` | override the detected project root |
| `DQXI_START_SECTION` | `editor`, `maps`, `models`, `textures`, `code`, … |
| `DQXI_EDITOR_MAP` | pre-select a map id (for example `b001_101a`) |

## Editor

The editor reads `game_assets/maps/<map>/scene.json`. It renders the converted environment OBJ,
draws placement markers, edits position/scale/rotation, and writes:

- `editor_projects/<map>.json` — editable project;
- `game_assets/maps/<map>/level3d.patched.bxon` — same-size binary patch.

Use `python tools/patch_game.py --map <map>` to rebuild a modified ROM.

## Tests

```powershell
cargo test
```

The 9 tests cover camera drag conventions, corrupt-vertex repair, map-id mapping, editor scene
JSON round-trip, bounded float patching, and transform validation.

## Data directories

The app prefers `game_assets/` when present and falls back to the older curated
`game_textures/`, `game_models/`, etc. The boot bar reports the number of indexed items for each
library. If an index is empty, run the corresponding converter in `../tools/`.
